# Agent Context

Автоматическое сжатие результатов инструментов для **Codex, Claude Code и Hermes**. Один пакет: контролируемый SuperCompress, локальный Headroom, необязательная телеметрия Langfuse, диагностика и совместимые автообновления. Обычный вход агента сохраняется.

## Установить через агента

Вставьте в любой из поддерживаемых агентов:

> Установи сжатие из https://github.com/taskqorg/agent-context. Прочитай INSTALL.md, проведи онбординг, проверь конфликты и сообщи, что работает и что ещё требует настройки.

Агент проверит среду, поможет с ключом SuperCompress, настроит установленных агентов и проверит сервисы. Windows и WSL настраиваются отдельно; расположение проекта не меняет среду агента.

Для подготовленной среды одна команда:

```sh
npm exec --yes --ignore-scripts --package=github:taskqorg/agent-context -- agent-context setup
```

Нужны Node.js 22+, npm, Git, Python 3.11–3.13 с `venv`/`ensurepip` и ключ SuperCompress. [Релиз 0.1.14](https://github.com/taskqorg/agent-context/releases/tag/v0.1.14) квалифицирован на macOS (Codex, Claude Code); автообновление пока раскатывается только на macOS. 0.1.12 проверен на macOS, Windows, WSL и Linux. Автообновления принимают совместимые стабильные patch-релизы: проверка не чаще раза в сутки при запуске launcher, без прерывания активных клиентов. Подробная процедура: [INSTALL.md](INSTALL.md).

## Удалить через агента

> Полностью удали Agent Context по процедуре INSTALL.md: останови его сервисы, убери интеграции, восстанови мои настройки и удали локальные файлы пакета. Не удаляй входы агентов и общие ключи сервисов.

Сначала закройте другие агентские сессии, использующие сжатие. Из установленного CLI либо подготовленного checkout:

```sh
agent-context uninstall --dry-run
agent-context uninstall
```

Без глобального CLI: `node ~/.agent-context/launcher.mjs uninstall` (в Windows агент подставит путь своего профиля). Для прежних версий без этой команды используйте `node bin/agent-context.js uninstall` из текущего checkout.

Удаление откатывает всю сохранённую историю установки, сохраняет более поздние изменения других настроек, удаляет наши хуки/MCP/плагин, приватное окружение Python, версии, кэш, инциденты, резервные копии и global npm-пакет. При конфликте или занятом сервисе останавливается с объяснением; принудительного удаления нет. Общие ключи SuperCompress/Langfuse и авторизация агентов остаются. Затем перезапустите агентские соединения.

## Проверка и восстановление

```sh
agent-context doctor --fix --live
agent-context update status
```

Doctor исправляет только принадлежащие пакету регистрации и сервисы. Сжатие при ошибках сохраняет исходный результат. Успешный doctor подтверждает здоровье сервисов; реальную экономию проверяют отдельным агентским вызовом.

Онбординг предупреждает о другом сжатии. Публичные инциденты содержат только разрешённые метаданные, без запросов, исходного текста и ключей; По умолчанию отправка идёт анонимно через relay (без GitHub-аккаунта, дедуп и счётчики на сервере); `agent-context incidents show` показывает, что уйдёт; `setup --no-report` отключает отправку; `incidents enable --gh` — отправка от вашего GitHub-аккаунта.
