21	## Product behavior
22	
23	- **P1 — Package.** MUST install, diagnose, update and remove its own integration reversibly. Preserve unrelated settings and active sessions. Report deferred updates.
24	- **P2 — Interception.** MUST use the supported client recipe. Proxy and hook adapters share provider selection, safeguards and event semantics. Never compress the same block twice.
25	- **P3 — Providers.** MUST support selectable `headroom-local`, `supercompress` Neural, and `scaledown` adapters. One provider per agent profile; no silent fallback to another provider. Local mode requires no cloud key or model download.
26	- **P4 — Safety.** MUST preserve user requests, auth, tool IDs, error evidence, signed thinking and previously transmitted prefixes. Compress eligible new tool results before model submission. Keep the original on timeout, invalid output or failed validation; report the reason.
27	- **P5 — Originals.** MUST allow original retrieval without recompression. Bound storage and retention; report expiry. Production artifacts cannot depend on temporary directories.
28	- **P6 — Reliability.** MUST bound request size, concurrency, timeout, memory, storage and telemetry queues. Telemetry failure must not block agent work. No process-wide termination during an update.
29	- **P7 — Control.** MUST show configured and actual running package/provider/config versions separately. Support enable, disable, provider switch and rollback per agent profile.
