# Mac qualification and setup

Owner authorizes installing this package for Codex, Claude Code and Hermes. TaskQ/ARM/production remain paused. No provider login changes, paid model turns or automatic app termination.

1. Verify the received archive SHA256 before extracting or installing. Preserve the existing private inventory and backups. Do not print any credential values.
2. Unpack source in a separate local directory. Run `npm ci --ignore-scripts`, `npm test` and `npm pack`. Confirm Node 22+, native config paths and actual Hermes profile. The package operates on the default user profile; report additional profiles rather than assuming coverage.
3. Keep the owner-provided current key in a local secret path. Use `agent-context set-key` through private stdin only if the existing key is obsolete. Reconcile stale environment variables; Finder and terminal inheritance differ. Neither install nor integration rollback changes login/shell environments.
4. Install the pinned tgz globally. Run `agent-context install codex claude hermes`. This backs up modified files, removes legacy SC hooks, moves a legacy Hermes SC plugin outside active plugins, and installs native MCP plus the Claude Bash replacement hook. It preserves other settings; unsupported shapes/symlinks stop instead of overwriting.
5. Run `agent-context doctor` from a neutral directory and each target project. Investigate duplicate registrations, project overrides, additional profiles, old Hermes SOUL/skills/plugin instructions and other global compression plugins. Do not disable native agent conversation compaction merely because SC is installed: these mechanisms serve different purposes.
6. Run `agent-context verify codex`, `verify claude`, `verify hermes`. These perform synthetic native stdio and hook-command tests, no model turns. Record latency, retention, repeats and package version.
7. Reload each client's MCP or ask owner for a normal restart when necessary. Verify actual client-side tool availability and one synthetic MCP/hook invocation. Do not claim live hooks based solely on doctor or subprocess checks. Follow the client's hook trust mechanism; do not forge approval hashes.
8. Before the final production installation, prove rollback in an isolated home with all three config fixtures: exact-byte restore, legacy plugin restore, refusal on later edits. The shared unit suite covers this; add actual Mac file/process evidence. Never test rollback by destroying the owner's later edits.
9. Return a sanitized report: installed recipe and archive SHA, versions, paths, changed files/transaction id, doctor output, native test results, actual-client results, latency and quality, unresolved profile/reload limitations and exact rollback command. Distinguish text reduction from actual model-input savings. Do not claim Hermes hook interception: this adapter is MCP-only.

Failure criterion: missing/old key, duplicate active compressor, wrong executable path, callback shape mismatch, lost control error, endless retry, stale module or config drift. Preserve originals and report the specific layer; do not compensate by increasing all timeouts or changing provider auth.

No daemon, new telemetry service, LangGraph migration, self-healing updater or latest-version auto-install is part of this release. Runtime metadata is local, bounded and content-free. Later telemetry can consume it without becoming a prerequisite for agent work.
