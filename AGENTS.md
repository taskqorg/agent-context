# Agent Context

Для установки, онбординга или удаления по просьбе пользователя прочитайте [INSTALL.md](INSTALL.md).

Для изменений кода: сохраняйте обычный вход и approval policy агентов; не выводите секреты. Проверяйте изменения в изолированном `AGENT_CONTEXT_HOME`; CLI uninstall дополнительно требует изолированный `npm_config_prefix`, иначе удалит настоящий global npm-пакет. Unit tests подменяют эту операцию. Канонический gate — `npm test`, затем `npm pack`. Квалификация кандидата не является разрешением развернуть его в рабочих профилях или объявить стабильным релизом.
